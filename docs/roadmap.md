## Подключение LLM МАИ

Доступ предоставлен через https://api-ai.mai.ru/; реализован `MAIProvider` через существующий `LLMProvider`. Model Checker остаётся детерминированным, `fake` сохраняется для воспроизводимого показа, OpenRouter — как альтернативный провайдер.

16.10.2026 проверены официальный OpenAPI, авторизация, маршруты и реальные запросы. По контрольным прогонам выбрана `qwen3.6-35b-a3b`; `deepseek-v4.1-flash` также прошла ошибочный acceptance-сценарий, `Qwen3.5-122B-A10B` дала невалидный DSL. Название модели и совместимость необходимо перепроверять при изменении сервиса.

Ключ хранится локально в backend `.env` или окружении, не попадает в Git, frontend, issues и логи. Ошибка объяснения больше не скрывает результат TLC. [Отчёт оценки](llm-quality.md) содержит сценарии, ожидаемую семантику, результаты и обнаруженные ограничения. Неполные требования требуют уточнения; валидная модель и `PROPERTY_HOLDS` не доказывают правильность интерпретации.

## Ресурсы практики

По информации организаторов:

- `gitlab.mai.ru` — основной репозиторий практики и площадка CI/CD. Текущий рабочий репозиторий — GitHub; перенос и синхронизацию согласуем отдельно, remote сейчас не меняем.
- Сфера.Задачи, Сфера.Знания, Сфера.Код — планирование, артефакты и дублирование кода. Конкретный порядок использования уточняем у организаторов.
- Анализатор ИСП РАН подключаем после отдельной инструкции по пайплайнам.
- Сайбокс доступен для автоматизации; применяем при конкретной необходимости.
- Ресурсы Яндекс Облака запрашиваются с обоснованием; минимальные ВМ доступны, более тяжёлые ресурсы и ServerLess — позже. Деплой не является обязательным результатом первой предзащиты.
- A100 в кластере МАИ, Jupyter Notebook и S3 предоставляются по запросу для обучения. Текущий кейс использует готовую LLM; отдельное обучение модели пока не требуется.

Доступ к LLM и ресурсам согласуется с Петром Александровичем Уховым. Наличие ресурса не означает, что он уже подключён к проекту.

После ближайших этапов по обратной связи определить необходимость лимита состояний, отдельной проверки SANY и расширения диалога уточнений. Не добавлять инфраструктуру без конкретной задачи.
