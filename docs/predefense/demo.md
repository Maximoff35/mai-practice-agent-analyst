# Сквозная демонстрация MVP

Запустите backend и frontend по [общей инструкции](../../README.md).
Для воспроизводимой предзащиты задайте backend `LLM_PROVIDER=fake`.
Это демонстрационный провайдер модели и объяснения; проверяет модель настоящий TLC.

## Нарушение свойства

В интерфейсе нажмите «Подставить пример». Текст:

> Заявка после согласования может быть исполнена. Пользователь может отменить заявку до исполнения.

После анализа покажите модель: `Cancel` не сбрасывает `approved`, а `Execute`
проверяет только `approved=true`. Свойство запрещает сочетание
`status=Executed AND cancelled=true`.

Ожидаются `PROPERTY_VIOLATED` и контрпример:

| Шаг | Переход | status | approved | cancelled |
| --- | --- | --- | --- | --- |
| 1 | Начальное состояние | Created | false | false |
| 2 | Approve | Approved | true | false |
| 3 | Cancel | Cancelled | true | true |
| 4 | Execute | Executed | true | true |

Объяснение связывает нарушение с сохранённым разрешением после отмены.
Это вывод о построенной модели; неверная интерпретация требований тоже
может быть причиной нарушения.

## Явное исправление

Нажмите «Новая модель» и добавьте предложение:

> При отмене заявки approved = false.

Повторный анализ должен вернуть `PROPERTY_HOLDS`, показать новый эффект
в `Cancel` и отсутствие контрпримера. Агент не исправляет модель автоматически.

## Ошибки

- Пустой текст: кнопка анализа недоступна.
- В режиме `fake` введите «Проверить движение лифта»: backend вернёт 422,
  интерфейс покажет ограничение демонстрационного провайдера без старого результата.
- Остановите backend и повторите анализ: интерфейс покажет ошибку доступности,
  а не подставной контрпример. После запуска backend анализ можно повторить.
- `TIMEOUT` и `STATE_LIMIT_REACHED` не считаются успешной проверкой.

## Разделение компонентов

Браузер → Next.js `/api/analyze` → FastAPI → Analyst Agent → BehavioralModel →
Validator → TLA+ → Java/TLC → результат и трасса → объяснение → интерфейс.
Next.js только пересылает JSON; Model Checker не использует LLM.
Ключи провайдера остаются на backend, адрес FastAPI задаётся серверной
переменной `BACKEND_URL`. Для свободного текста используйте OpenRouter,
учитывая возможные ошибки внешнего API и формализации.
